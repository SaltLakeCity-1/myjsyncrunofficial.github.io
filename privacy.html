Privacy Policy

This policy describes how Salt Lake City Automations (the “Bot”) handles information when installed in a Discord server and used with the code supplied for this project.

Who operates the Bot

Operator: Myjsyncrunofficial
Contact: saltlakecity70@gmail.com

The server owner or operator running the Bot is responsible for its hosting, configuration, access controls, and any code changes.

Information the Bot handles

When someone runs a Bot command, Discord sends the interaction data needed to process it. The Bot uses command options, the Discord server ID, and relevant Discord account IDs and names to respond and carry out the requested action. It does not request message-content access.

When authorized staff use /moderate, the Bot saves a case containing the action, moderated member’s Discord ID and tag, staff member’s Discord ID, reason entered by staff, and date and time. Cases are stored in JSON files on the computer or server where the Bot runs. The current code keeps these records until the Bot operator deletes them; it does not provide an automatic deletion schedule.

If configured with an ER:LC server API key, the Bot sends that key to the ER:LC API to request server status. The key is read from the Bot operator’s environment configuration. The /server command and optional status polling use the API response to show server information. ER:LC handles those requests under its own terms and privacy practices.

How information is used

The Bot uses information to respond to commands, create and display moderation case records, perform Discord kick or ban actions requested by staff, and, if configured, retrieve ER:LC server status. It does not sell information or use it for advertising.

Storage, access, and sharing

Moderation case files are stored locally with the Bot and are accessible to people who can access the computer, hosting account, backups, or files where the Bot runs. The supplied code does not encrypt these JSON files. The Bot operator should restrict access to the host and backups and must not publish .env files, tokens, API keys, or case files.

The Bot exchanges command and server data with Discord so it can operate. If ER:LC status features are enabled, it also communicates with the ER:LC API. Discord and ER:LC process information under their own policies. The Bot operator may disclose information if required by law or to protect the security of the Bot or server.

Retention and deletion

Moderation records remain in the local case file until the Bot operator deletes them. To request access to or deletion of a case, contact the Bot operator using the contact information above and include the case ID if available. A server owner or Bot operator can also remove records directly from the server’s case JSON file. Deleting records from the Bot does not delete copies in backups or records held by Discord or ER:LC.

Children

The Bot is intended for use in Discord communities and is not designed to collect information from children. Server owners and operators must use the Bot in compliance with applicable age and privacy laws and Discord’s rules.

Changes and contact

This policy may be updated when the Bot’s features or data handling change. Questions or requests can be sent to saltlakecity70@gmail.com.
